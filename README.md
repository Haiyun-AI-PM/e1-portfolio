# E1 创建项目 · 个人作品集初始页

> EduSeed「经验作品集」课程 E1 挑战的交付仓库：一个可运行、可预览的个人作品集初始页，含首次 Git 建仓与规范提交，以及完整的 AI 协作过程材料。

## 项目简介

这是为课程挑战 **E1 创建项目** 生成的作品集初始页，采用原生 HTML / CSS / JS 三件套实现「结构 / 样式 / 行为」分离：

- 首页包含顶部导航、首屏（hero）、关于我、项目卡片、联系方式与页脚；
- 当前内容为**占位**（如 `[你的名字]`、示例项目卡片），将在 E2–E6 中逐步替换为真实个人介绍与项目；
- 代码带注释，CSS 使用 `:root` 设计变量统一颜色/字体/间距，方便后续换肤与增量迭代。

课程目标：经过 E1 → E6 六个挑战，把这个初始页迭代成一个可公开访问、可包装复用的个人作品集。

## 快速开始

仓库为纯静态页面，无构建步骤，两种方式均可本地预览：

```bash
# 方式一：用浏览器直接打开
open index.html

# 方式二：本地起一个静态服务（推荐，行为与线上更一致）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
