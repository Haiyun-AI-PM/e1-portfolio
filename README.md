## 快速开始

仓库为纯静态页面，无构建步骤：

```bash
# 方式一：用浏览器直接打开
open index.html

# 方式二：本地起静态服务（推荐，行为与线上一致）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
